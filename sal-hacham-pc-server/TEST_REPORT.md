- Lazy loading ורשימת חנויות מתקפלת.

## Live integration
חוזה ה-API של ה-adapter תואם לממשק המתועד של `il-supermarket-scraper 1.0.8`: `ScraperFactory.all_scrapers_name()`, `enabled_scrapers`, `files_types`, `output_configuration`, `status_configuration` ו-`single_pass=True`.

### מגבלת סביבת הבדיקה
ניסיון להתקין את `il-supermarket-scraper==1.0.8` מתוך סביבת ה-container נכשל בגלל חסימת DNS/אינטרנט של הסביבה, לא בגלל dependency resolution. לכן לא בוצעה הורדה חיה פיזית מכל אתרי הרשתות מתוך ה-container. ה-adapter נבדק עם mock, והחוזה שלו הושווה לתיעוד הנוכחי של גרסה 1.0.8.

## מסקנה
אין כרגע באג ידוע במסלולים שנבדקו. אין דרך כנה להבטיח "אפס באגים" בכל נתון עתידי של כל רשת, אבל סל, קופונים, מבצעים, API, UI, freshness, DB וה-regressions עברו בדיקה רחבה לפני האריזה. סביבת העבודה הנוכחית אינה כוללת `pytest` ו-`FastAPI`, ולכן חבילת בדיקות Python המלאה לא הורצה מחדש; בדיקות הליבה החדשות הורצו ישירות מול SQLite וקבצי Python עברו `compileall`.
